# Geometric Modelling

Python implementations of numerical methods studied in the *Geometric Modelling* course of the Master's programme in Applied Mathematics at Université Grenoble Alpes / Grenoble INP.

## Overview

This repository brings together practical assignments exploring numerical interpolation and the differential geometry of parametric curves.

## Topics

### 1. Polynomial Interpolation

- Lagrange and Hermite interpolation
- Newton interpolation
- Runge's phenomenon
- Curve interpolation with tangent constraints

### 2. Differential Geometry of Curves

- Parametric curves in 2D and 3D
- Numerical differentiation
- Tangent and normal vectors
- Curvature and centres of curvature
- Computation and visualization of evolutes

## Technologies

- Python
- NumPy
- Matplotlib

## Repository Structure

The repository will contain Jupyter notebooks with numerical implementations, experiments and visualizations.

## Academic Context

These exercises were completed as part of the *Geometric Modelling* course in the Master's programme in Applied Mathematics.

The repository presents my own implementations and numerical results.
